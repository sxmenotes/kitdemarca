# Click! Acepto — Kit de marca para Canva IA

Sitio estático con la identidad aprobada de Click! Acepto — by Kintu: logos, paleta, tipografías, reglas de composición, formatos sociales, planes, precios, instrucciones para Canva IA y JSON estructurado.

## Archivos

- `index.html`: documento autocontenido, con logos integrados y descargables.
- `recursos/`: logos originales SVG y PNG para carga independiente en herramientas de diseño.
- `favicon.svg`: icono de pestaña.
- `vercel.json`: configuración del sitio estático.

No requiere Node.js, instalación de dependencias ni compilación. No incluye editor, clientes, fuentes de sistema ni datos privados.

## Desplegar en Vercel

1. Importar este repositorio desde GitHub.
2. Elegir Framework Preset **Other** y Root Directory **.** (raíz).
3. Dejar Build Command sin comando; Output Directory **.**. La configuración está en `vercel.json`.
4. Desplegar y verificar en la URL final la portada, los enlaces internos y la descarga de logos.

Para revisión local, abrir `index.html` en el navegador. Los logos también están embebidos, por lo que el documento no depende de servicios externos.

Este HTML es un brief para IA, no una plantilla nativa de Canva. Si Canva no acepta el archivo, copiar las instrucciones y subir los recursos por separado. Las fuentes no se distribuyen; verificar disponibilidad y licencia en la herramienta de destino.

La publicación del sitio no conecta cuentas de Canva ni publica en redes sociales. Los precios incluidos corresponden a la información aprobada al preparar el kit; revisar antes de reutilizarlo.
